# Luma 0.2.4

Discord'un kendi güncelleyicisi korunur. Luma bağlantısı açıkken yeni Discord işlemleri kontrol edilir; güncelleme veya normal açılışta proxy ayarları kaybolmuşsa Discord nazikçe kapatılıp doğru ayarlarla yeniden açılır. Ayarlar'daki “Discord bağlantısını otomatik koru” seçeneği varsayılan olarak açıktır.

Çalışan ve doğru yapılandırılmış oturumlar yeniden başlatılmaz. Luma bağlantısı kapalıyken müdahale edilmez. Okunamayan işlem bilgisi yeniden başlatma sebebi değildir. İki dakikada en fazla üç otomatik deneme yapılır. Zorla kapatma, sistem proxy değişikliği, Discord paketini değiştirme veya güncellemeleri devre dışı bırakma uygulanmaz.

Bu davranış için Luma'nın ve bağlantısının açık olması gerekir; pencere kapatılabilir. Güncelleme denetimi ve kurulumu Discord'un kendi güncelleyicisine aittir.

28 birim testi geçti. ARM64 geliştirme paketi; Developer ID imzası ve notarizasyon içermez. PS5 yardımcısına ilişkin önceki macOS kayıt sorunu bu sürümün kapsamı dışındadır.
